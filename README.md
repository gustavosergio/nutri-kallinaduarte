# Kallina Duarte — site demonstrativo

Site estático responsivo, sem dependências de instalação. Abra `index.html` ou execute `python -m http.server 8080` nesta pasta.

Conteúdo baseado nas informações fornecidas do perfil @nutri.kallinaduarte. Agendamento pelo link original da bio: https://bit.ly/4bi10dR. Nenhum telefone, depoimento, preço ou resultado clínico foi inventado. A vivência com o autismo é apresentada como história pessoal, sem atribuir especialização profissional.

Foto de perfil: Instagram público de Kallina. Foto de alimentos ilustrativa: https://unsplash.com/photos/1511690743698-d9d85f2fbf38 (arquivo servido por images.unsplash.com/photo-1511690743698-d9d85f2fbf38). Tipografia via Google Fonts, com alternativas locais.

Site demonstrativo sujeito à aprovação da profissional antes de uso oficial.
